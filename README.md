# C++ Flashcard Quiz — GUI

Графический тренажёр на PyQt6. Поддерживает два режима:
- **Flashcard** — знаю / не знаю (работает сразу, без импорта ответов)
- **4 варианта** — правильный + 3 неверных (нужен импорт JSONL с ответами, сгенерированными ИИ)

## Быстрый старт

```bash
pip install -r requirements.txt
python -m quiz_gui.main
```

Кнопка **«Обновить индекс»** на главном экране загружает вопросы из папки `content/` в БД. Сделай это при первом запуске.

## Импорт ответов (для режима 4 вариантов)

Сгенерируй ответы через OpenAI:

```bash
export OPENAI_API_KEY=sk-...
python scripts/generate_answers.py             # все 18 000+ вопросов
python scripts/generate_answers.py --end 100  # только первые 100 (для теста)
```

Или вручную создай JSONL-файл:

```jsonl
{"qid": 1, "correct": "Именованная область памяти...", "wrong": ["Тип данных", "Функция", "Оператор"]}
{"qid": 2, "correct": "...", "wrong": ["...", "...", "..."]}
```

`qid` — глобальный номер из `questions_export.txt` (получить: `python scripts/export_questions.py`).

Загрузить через UI: кнопка **«Импорт ответов»** → выбрать `.jsonl` файл.

Или через CLI:
```bash
python -m quiz_gui.importer answers.jsonl
python -m quiz_gui.importer answers.jsonl --reset   # перезаписать старые ответы
```

## Управление в квизе

Раскладка кнопок ответов — как в vim (hjkl):

```
        [k]
  [h]         [l]
        [j]
```

| Клавиша | Действие |
|---|---|
| `k` | Вариант сверху |
| `h` | Вариант слева |
| `l` | Вариант справа |
| `j` | Вариант снизу |
| `w` | Помощь из космоса |
| `e` | Пропустить вопрос |
| `q` | Выйти из сессии |

Работает на **любой раскладке клавиатуры** (в том числе на русской).

В режиме **Flashcard**: `h` = Не знаю, `l` = Знаю.

На каждой кнопке ответа — еле заметная подсказка `[h]` / `[j]` / `[k]` / `[l]` в верхнем левом углу.

**Таймер**: настраивается при запуске (по умолчанию 60 с, диапазон 10–300 с). Становится красным при < 10 с. При истечении — `timeout`, переход к следующему.

**Помощь из космоса (w)**: фоновый запрос к [RANDOM.ORG](https://www.random.org) (атмосферный шум), seed подсвечивает один вариант синим. Выбор за тобой — можно нажать любой `h/j/k/l`.

## Настройки квиза

Перед каждым запуском открывается диалог с настройками:
- **Режим**: Flashcard или 4 варианта
- **Разделы**: выбор тем чекбоксами (01_cpp, 02_algorithms_and_ds, …)
- **Количество вопросов**: 1–500
- **Время на вопрос**: 10–300 с

## Файловая структура

```
quiz_gui/
├── main.py              # QApplication, QMainWindow, роутинг между экранами
├── db.py                # SQLite схема + все запросы
├── importer.py          # импорт JSONL → answer_options
├── screens/
│   ├── home.py          # главный экран (статистика, выбор игрока, кнопки)
│   ├── quiz.py          # экран квиза (таймер, cosmic, ответы)
│   └── results.py       # результаты + matplotlib-графики
└── widgets/
    └── answer_button.py # QPushButton с подсказкой [h] в углу
scripts/
├── export_questions.py  # экспорт всех вопросов в txt для генерации ответов
└── generate_answers.py  # генерация ответов через OpenAI API
quiz_gui/app.db          # локальная БД (в .gitignore — не попадает в репо)
```

## БД

SQLite, `quiz_gui/app.db`. Таблицы:

| Таблица | Содержимое |
|---|---|
| `users` | Игроки |
| `questions` | Вопросы с `global_id` (совпадает с номером в `questions_export.txt`) |
| `answer_options` | Варианты ответов (1 верный + 3 неверных на вопрос) |
| `sessions` | Каждый запуск квиза, режим (`flashcard` / `quiz`) |
| `responses` | Ответы: выбранный вариант, `is_correct`, время, рейтинг |

Рейтинги ответа: `correct`, `wrong`, `skip`, `timeout`, `cosmic`.

## Графики после сессии

- **Pie chart** — распределение correct / wrong / skip / timeout / cosmic ✓ / cosmic ✗
- **Bar chart** — точность по категориям (разделам)
- **Line chart** — время на каждый вопрос (оранжевая = среднее, красная = лимит таймера)
